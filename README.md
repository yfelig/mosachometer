# מוסכּומטר 🔧🚗

השוואת מחירי תיקונים במוסכים — פרויקט קוד-פתוח של חברים.

חברים נכנסים ללינק, מזינים תיקון שעשו (מה, כמה עלה, באיזה מוסך), והאתר מחבר
את כל הדיווחים ומראה אילו מוסכים יקרים או זולים **באופן עקבי**.

## איך זה בנוי

- **Frontend**: עמוד סטטי אחד (`index.html`) על GitHub Pages — אין שרת.
- **Data**: טבלה אחת ב-[Supabase](https://supabase.com) (Postgres). הדפדפן כותב/קורא ישירות דרך ה-anon key, עם RLS שמתיר רק הוספה+קריאה.
- **חיבור מוסכים (matching)**: כל דיווח מקובץ למוסך לפי **מספר טלפון** מנורמל (העוגן החזק); אם אין טלפון — לפי שם+אזור מנורמלים.
- **מדד מחיר**: כל תיקון מנורמל מול הממוצע של אותו *סוג* תיקון (100 = ממוצע). ככה משווים תפוחים לתפוחים, וניתן לדרג מוסכים על פני סוגי תיקון שונים.

## הקמה (פעם אחת)

1. צרו פרויקט חינמי ב-[supabase.com](https://supabase.com).
2. **SQL Editor → New query** → הדביקו את `supabase-schema.sql` → **Run**.
3. **Project Settings → API** → העתיקו את `Project URL` ואת `anon public key`.
4. ערכו את `config.js` עם שני הערכים האלה.
5. דחפו ל-GitHub — GitHub Pages מגיש אוטומטית.

זהו. שלחו את הלינק לחברים.
